# RunningHub 故事视频

输入故事/剧本、目标时长、画幅、风格和可用参考图；输出逐镜提示词、参考资产、画布与节点记录、生成和审片结果。采用当前 UI 中可用的 MiniMax 工作流；`MiniMax H3 RH Enhanced` / `全能参考` 是已观察的组合，名称和可用性必须现场核实。

## 依赖与状态归属

- 需要支持 Skill 的代理环境、单独安装的 `ego-browser` Skill/Ego Lite，以及使用者自己的 RunningHub 登录。按激活名称查找浏览器 Skill，不假定其与本 Skill 相邻。不使用 RunningHub 私有 API 绕过页面。
- 单独安装可在用户指定的项目目录维护记录，格式见 [记录模板](references/records.md)。与本仓库一起使用时遵循工作区 `AGENTS.md`、`projects/AGENTS.md`，由 `projects/new_project.py` 建项目；队列和工作台是可选集成。
- 创作、资产与运行状态归作品目录；可复用规则归 Skill。保留旧版本和原任务身份，不能把安装 Skill 视为付款或发布授权。

## 流程

1. 确认故事、时长、画幅、参考图与交付方式；能合理推断的普通规格不反复询问。用户只要方案时完成方案，不打开生成任务。
2. 先研究事实与含混意象，把事实来源、解读和创作选择分开。写故事结构、剧本和有闭合时间轴的分镜；每镜以一个主要动作承担叙事。
3. 盘点全部人物、场景和独立道具。每项适用参考图完成正面、侧面、背面三视图，检查同一身份、造型、尺寸、光向与空间布局。图像生成工具由使用者选定；图像上传节点不等于图像生成工具。
4. 写逐镜提示词和下面的完整摄影调度；引用当前精确文件名/资产版本。与真实场景三视图对照，路径矛盾时先改参考图。
5. 每个作品一个 Ego Lite TaskSpace、一张 RunningHub 画布，全部镜头共用该画布。参考图放左，编号镜头按序放右，卡片间距充分、连线不穿卡片。多作品仅在用户或工作区允许独立浏览器时分别处理；不能绕过已交还用户的控制权。
6. 阅读 [操作经验](references/runninghub-operations.md)。逐节点确认账号、模型、模式、引用、时长、画幅、分辨率与费用。先看已有任务再提交，不能把慢响应当失败重复生成。
7. 记录节点身份、提示词/参考版本、报价和运行结果。逐镜检查首/中/尾帧与运动停点；不通过时先诊断再返工。生成成功不等于审片通过。
8. 在线交付保留视频在画布；只有用户要求本地文件才下载到其项目。剪辑前核对来源、顺序、裁切、间隙、画幅和总时长。记录草稿与导出状态，直到输出节点实际可播放才标为完成。

## 摄影调度门槛

每镜在分镜和提交提示词中写全：

- **start**：起始景别、机位方位/高度、观看轴线、主体位置与首个动作。
- **move**：锁定、推拉、横移、摇、俯仰、环绕等；写方向、速度/幅度与时间段。多段明确切点。
- **stop**：停在哪个动作或空间标记、何时稳定、最终景别/构图与必须留下的内容。
- **continuity**：出入画、视线轴和下一镜承接；运动在所选时长与真实场景空间内可执行。

“电影感运镜”不算摄影计划。模型忽略运动或末帧构图时应记返工，不用“氛围很好”替代目标验证。本地 --ready 校验检查记录完整性，不能证明画面质量、现场上传或付款授权。

## 费用、队列与恢复

- 默认没有积分授权。免费/明确零费用任务在依赖就绪后可执行；积分任务需当前用户明确授权平台、预算与时间，并逐节点核对现价和余额。配置 true、历史授权或旧报价不能自行授权新的使用者。
- 不消费现金钱包，不购买/充值积分。费用类型不清、余额不足或超预算时暂停该项并写原因，不重复询问已经在当前上下文明确提供的授权。
- 可选队列使用用户配置的时区和窗口；默认 Asia/Shanghai、21:00 只是样例。YAML 不会自动创建定时器，也不会唤醒设备或浏览器。
- 登录、验证码、权限提示交还用户在原空间处理。用户接管后停止；经用户明确恢复才继续同一空间。原空间无法恢复时记录 waiting_browser，不另开空间逃避交接。
- 超时只说明观察结束；先检查原任务身份与在线状态，再决定是否重试。恢复保留成功镜头，只处理失败或拒绝项。每次返工重新核价。

## 验证与限制

画布节点和浏览器 UI 会变；当前费用、免费活动、模型和并发以现场为准。浏览器流程依赖代理宿主和 Ego Lite，本 Skill 不自带执行器或长期登录。发布版的教学项目没有在 RunningHub 提交任务；示例图不代表模型效果。

构图/连续性可参考 [跨模型改写](references/awesome-seedance-adaptation.md)，不能把 Seedance 专有语法或模型能力直接当 MiniMax 规格。

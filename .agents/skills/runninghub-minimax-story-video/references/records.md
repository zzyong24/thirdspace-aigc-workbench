# 单独使用时的记录模板

Skill 不强制安装工作台。选择用户指定项目目录，保留方案、研究、剧本、分镜、资产索引、提示词和 run-log.md。所有状态属于该作品。

每项资产记录：ID、人物/场景/道具、当前版本、三视图路径、适用镜号、生成/检查/上传状态、来源与许可。每镜记录：唯一镜号、时长、主体动作、参考文件版本、start/move/stop/continuity、生成参数、节点 ID 与画布链接。

每次运行追加：时间与时区、原浏览器空间/节点身份、提示词版本、现场报价类型与金额、余额核验、提交/运行/成功/失败状态、首/中/尾审片、试听状态与采用版本。不得记录密码、Cookie、Token。公开分享前移除私人账号、画布和素材。

使用工作台时，字段结构见仓库 docs/records.md，运行时由项目目录中的版本化 YAML 维护数据。即使 --ready 通过，也要现场确认当前 UI、费用授权与参考图真实上传。

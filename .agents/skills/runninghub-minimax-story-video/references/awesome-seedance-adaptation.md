# 从 Seedance 示例借鉴镜头语言

可选参考库：[LearnPrompt/awesome-seedance](https://github.com/LearnPrompt/awesome-seedance)。由使用者另行克隆或在线阅读，不随本 Skill 分发。

优先借鉴时间轴、人物身份/服装连续性、分镜网格和可执行摄影语言。保留一镜一个主要动作、明确首尾状态、完整运动方向与停点；将提示词改写为当前 MiniMax UI 支持的规格。

不要直接复制 Seedance 专有语法、引用帧假设、控制参数或模型能力；同一语法在不同模型上未必有效。模型、参考数、时长、分辨率、画幅和费用以当前节点为准。只读与作品相关的模板，注明实际使用的来源；事实、解读和创作选择分开记录。
